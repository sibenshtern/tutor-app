# Tutor App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended here) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the single-tutor web app from the spec: students, one-off and weekly recurring visits, per-visit payments, a dashboard, and analytics, deployable to Vercel + Neon.

**Architecture:** One Next.js 15 App Router app. Pure business rules live in `src/domain/` (no I/O, unit-tested). Prisma-backed services in `src/server/` take an explicit `now` so tests are deterministic. Server-component pages read through those services. Mutations go through thin Route Handlers in `src/app/api/**`, which share one wrapper for the session check, Zod parsing and error mapping. Clients always send local `YYYY-MM-DD` / `HH:MM` strings, and the server converts them using `APP_TIMEZONE`.

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS 4, Prisma 6, PostgreSQL (Docker locally, Neon in prod), Auth.js (`next-auth@beta`, v5), bcryptjs, Luxon, Zod 3, Recharts, Sonner, Vitest 3, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-07-tutor-app-design.md`

## Global Constraints

- Pinned majors: `next@15` (via `create-next-app@15`), `prisma@6` / `@prisma/client@6`, `next-auth@beta` (v5), `zod@3`, `vitest@3`. If an install resolves a different major, check its current API via context7 before writing code against it.
- Money: integer kopecks everywhere (`Int`), never floats or Decimal. RUB only. Convert to rubles only in the UI (`formatRub`, chart data).
- Time: DB stores UTC. All local interpretation goes through `src/lib/time.ts` with `APP_TIMEZONE` (default `Europe/Moscow`). Weeks start Monday. Never use `Date#getHours/getDate/...` in business logic.
- Only `completed` visits are charged. `paid ⇒ status === "completed"`. `Visit.rateKopecks` is a snapshot taken at creation.
- Error shape: `{ error: string, fields?: Record<string, string> }`. Status codes: 400 validation, 401 not signed in, 404 missing, 409 business rule, 500 unexpected.
- Mobile-first UI. Inputs use `text-base` (16px) so iOS doesn't zoom.
- **No git commits.** User preference, stored in memory. Leave all changes in the working tree. This replaces the skill's usual "Commit" steps.
- Integration tests use a real Postgres and mock only `@/lib/auth-guard`.

## Review Focus

1. A rate typed the Russian way, `"1 500,50"`, should save as 150050 kopecks, and garbage like `"abc"` should show a field error. Test in Task 2 (`parseRubles`).
2. An impossible date such as `"2026-02-30"` sent to the API should return 400 with a `date` field error, not 500. Test in Task 8.
3. Archiving a student with an active weekly lesson should end the series and remove its future scheduled visits, while past and completed visits stay. Test in Task 9.
4. Editing a series after cancelling one future occurrence should keep that occurrence cancelled and create no duplicate. Test in Task 9.
5. Logging in as `" Tutor@Example.COM "` should work, and failures with any casing should count toward the same rate-limit key. Test in Task 6.

`src/lib/money.ts`:

```ts
export function calcAmountDue(rateKopecks: number, durationMinutes: number): number {
  return Math.round((rateKopecks * durationMinutes) / 60);
}

export function parseRubles(input: string): number | null {
  const cleaned = input.replace(/[\s₽]/g, "").replace(",", ".");
  if (!/^\d+(\.\d{1,2})?$/.test(cleaned)) return null;
  return Math.round(Number(cleaned) * 100);
}

const whole = new Intl.NumberFormat("ru-RU", { style: "currency", currency: "RUB", maximumFractionDigits: 0 });
const fractional = new Intl.NumberFormat("ru-RU", {
  style: "currency", currency: "RUB", minimumFractionDigits: 2, maximumFractionDigits: 2,
});

export function formatRub(kopecks: number): string {
  return (kopecks % 100 === 0 ? whole : fractional).format(kopecks / 100);
}
```
`src/lib/time.ts`:
```ts
import { DateTime } from "luxon";

export const APP_TZ = process.env.APP_TIMEZONE ?? "Europe/Moscow";

export type Period = "week" | "month" | "year";

export function localToUtc(date: string, time: string, tz = APP_TZ): Date {
  const dt = DateTime.fromISO(`${date}T${time}`, { zone: tz });
  if (!dt.isValid) throw new Error(`Invalid local date/time: ${date} ${time}`);
  return dt.toJSDate();
}

export function utcToLocal(d: Date, tz = APP_TZ): DateTime {
  return DateTime.fromJSDate(d, { zone: tz });
}

export function localDateString(d: Date, tz = APP_TZ): string {
  return utcToLocal(d, tz).toISODate()!;
}

export function localTimeString(d: Date, tz = APP_TZ): string {
  return utcToLocal(d, tz).toFormat("HH:mm");
}

export function localKey(l: DateTime, period: Period): string {
  if (period === "week") return l.startOf("week").toISODate()!;
  if (period === "month") return l.toFormat("yyyy-MM");
  return l.toFormat("yyyy");
}

export function bucketKey(d: Date, period: Period, tz = APP_TZ): string {
  return localKey(utcToLocal(d, tz), period);
}

export function bucketLabel(key: string, period: Period): string {
  if (period === "year") return key;
  if (period === "month") return DateTime.fromFormat(key, "yyyy-MM").setLocale("en-GB").toFormat("LLL yyyy");
  return DateTime.fromISO(key).setLocale("en-GB").toFormat("d LLL");
}

export function addDays(isoDate: string, days: number): string {
  return DateTime.fromISO(isoDate, { zone: "UTC" }).plus({ days }).toISODate()!;
}

export function dateOnly(isoDate: string): Date {
  return new Date(`${isoDate}T00:00:00.000Z`);
}

export function isoFromDateOnly(d: Date): string {
  return d.toISOString().slice(0, 10);
}

export function formatDateTime(d: Date, tz = APP_TZ): string {
  return utcToLocal(d, tz).setLocale("en-GB").toFormat("ccc d LLL yyyy, HH:mm");
}
```

```ts
export type VisitStatus = (typeof VISIT_STATUSES)[number];

  return status === "completed";
}

  status: VisitStatus;
  paid: boolean;
  paidAt: Date | null;
  rateKopecks: number;
}

export interface VisitChange {
  status?: VisitStatus;
  paid?: boolean;
  paidAt?: Date;
  durationMinutes?: number;
  scheduledAt?: Date;
  notes?: string | null;
}

export interface VisitUpdateData {
  status?: VisitStatus;
  paid?: boolean;
  paidAt?: Date | null;
  durationMinutes?: number;
  amountDueKopecks?: number;
  scheduledAt?: Date;
  notes?: string | null;
}

export function planVisitUpdate(current: VisitState, change: VisitChange, now: Date): VisitUpdateData {
  const status = change.status ?? current.status;
  const paid = change.paid ?? current.paid;
  if (paid && status !== "completed") {
    throw new DomainError(
      current.paid && change.status !== undefined
        ? "Unmark this visit as paid before changing its status."
        : "Only completed visits can be marked paid.",
    );
  }

  const data: VisitUpdateData = {};
  if (change.status !== undefined) data.status = change.status;
  if (change.notes !== undefined) data.notes = change.notes;
  if (change.scheduledAt !== undefined) data.scheduledAt = change.scheduledAt;
  if (change.durationMinutes !== undefined) {
    data.durationMinutes = change.durationMinutes;
    data.amountDueKopecks = calcAmountDue(current.rateKopecks, change.durationMinutes);
  }
  if (change.paid !== undefined) {
    data.paid = change.paid;
    data.paidAt = change.paid ? (change.paidAt ?? (current.paid ? current.paidAt : now)) : null;
  } else if (change.paidAt !== undefined) {
    if (!current.paid) throw new DomainError("Only paid visits have a payment date.");
    data.paidAt = change.paidAt;
  }
  return data;
}
```

```ts
import { DateTime } from "luxon";
import { APP_TZ, localToUtc } from "@/lib/time";

export interface SeriesShape {
  weekday: number;
  startTime: string;
  durationMinutes: number;
  startDate: string;
  endDate: string | null;
}

export interface Occurrence {
  occurrenceDate: string;
  scheduledAt: Date;
}

export function occurrencesBetween(series: SeriesShape, from: string, to: string, tz = APP_TZ): Occurrence[] {
  const start = series.startDate > from ? series.startDate : from;
  const end = series.endDate && series.endDate < to ? series.endDate : to;
  if (start > end) return [];

  let day = DateTime.fromISO(start, { zone: "UTC" });
  day = day.plus({ days: (series.weekday - day.weekday + 7) % 7 });
  const last = DateTime.fromISO(end, { zone: "UTC" });

  const out: Occurrence[] = [];
  while (day <= last) {
    const occurrenceDate = day.toISODate()!;
    out.push({ occurrenceDate, scheduledAt: localToUtc(occurrenceDate, series.startTime, tz) });
    day = day.plus({ weeks: 1 });
  }
  return out;
}
```

```ts
import type { DateTime } from "luxon";
import { isCharged, type VisitStatus } from "@/domain/visit-rules";
import { APP_TZ, bucketKey, localKey, utcToLocal, type Period } from "@/lib/time";

export interface VisitFact {
  studentId: string;
  status: VisitStatus;
  scheduledAt: Date;
  durationMinutes: number;
  amountDueKopecks: number;
  paid: boolean;
  paidAt: Date | null;
}

export interface RevenueBucket {
  key: string;
  earned: number;
  received: number;
}

export interface StudentStats {
  completedVisits: number;
  hoursTaught: number;
  earnedKopecks: number;
  paidKopecks: number;
  owedKopecks: number;
  attendanceRate: number | null;
}

export const PERIOD_BUCKETS: Record<Period, number> = { week: 12, month: 12, year: 5 };

function shift(dt: DateTime, period: Period, n: number): DateTime {
  if (period === "week") return dt.minus({ weeks: n });
  if (period === "month") return dt.minus({ months: n });
  return dt.minus({ years: n });
}

export function revenueSeries(visits: VisitFact[], period: Period, now: Date, count: number, tz = APP_TZ): RevenueBucket[] {
  const current = utcToLocal(now, tz).startOf(period);
  const buckets = new Map<string, RevenueBucket>();
  for (let i = count - 1; i >= 0; i--) {
    const key = localKey(shift(current, period, i), period);
    buckets.set(key, { key, earned: 0, received: 0 });
  }
  for (const visit of visits) {
    if (!isCharged(visit.status)) continue;
    const earned = buckets.get(bucketKey(visit.scheduledAt, period, tz));
    if (earned) earned.earned += visit.amountDueKopecks;
    if (visit.paid && visit.paidAt) {
      const received = buckets.get(bucketKey(visit.paidAt, period, tz));
      if (received) received.received += visit.amountDueKopecks;
    }
  }
  return [...buckets.values()];
}

export function owedKopecks(visits: VisitFact[]): number {
  return visits.reduce((sum, v) => (isCharged(v.status) && !v.paid ? sum + v.amountDueKopecks : sum), 0);
}

export function attendanceRate(visits: VisitFact[]): number | null {
  const completed = visits.filter((v) => v.status === "completed").length;
  const noShows = visits.filter((v) => v.status === "no_show").length;
  return completed + noShows === 0 ? null : completed / (completed + noShows);
}

export const emptyStats = (): StudentStats => ({
  completedVisits: 0, hoursTaught: 0, earnedKopecks: 0, paidKopecks: 0, owedKopecks: 0, attendanceRate: null,
});

export function studentBreakdown(visits: VisitFact[]): Map<string, StudentStats> {
  const groups = new Map<string, VisitFact[]>();
  for (const v of visits) groups.set(v.studentId, [...(groups.get(v.studentId) ?? []), v]);
  const result = new Map<string, StudentStats>();
  for (const [studentId, group] of groups) {
    const charged = group.filter((v) => isCharged(v.status));
    const earned = charged.reduce((s, v) => s + v.amountDueKopecks, 0);
    const paid = charged.filter((v) => v.paid).reduce((s, v) => s + v.amountDueKopecks, 0);
    result.set(studentId, {
      completedVisits: charged.length,
      hoursTaught: charged.reduce((s, v) => s + v.durationMinutes, 0) / 60,
      earnedKopecks: earned,
      paidKopecks: paid,
      owedKopecks: earned - paid,
      attendanceRate: attendanceRate(group),
    });
  }
  return result;
}

export function formatAttendance(rate: number | null): string {
  return rate === null ? "—" : `${Math.round(rate * 100)}%`;
}
```

```ts
import { prisma } from "@/lib/db";

const WINDOW_MS = 15 * 60_000;
const MAX_FAILURES = 5;

export async function isRateLimited(keys: string[], now: Date): Promise<boolean> {
  const counts = await prisma.loginAttempt.groupBy({
    by: ["key"],
    where: { key: { in: keys }, createdAt: { gt: new Date(now.getTime() - WINDOW_MS) } },
    _count: { _all: true },
  });
  return counts.some((c) => c._count._all >= MAX_FAILURES);
}

export async function recordFailures(keys: string[], now: Date) {
  await prisma.loginAttempt.createMany({ data: keys.map((key) => ({ key, createdAt: now })) });
}

export async function clearFailures(keys: string[]) {
  await prisma.loginAttempt.deleteMany({ where: { key: { in: keys } } });
}

export async function pruneLoginAttempts(now: Date) {
  await prisma.loginAttempt.deleteMany({ where: { createdAt: { lt: new Date(now.getTime() - 86_400_000) } } });
}
```

```ts
import bcrypt from "bcryptjs";
import { prisma } from "@/lib/db";
import { RateLimitedError } from "@/lib/errors";
import { clearFailures, isRateLimited, recordFailures } from "@/server/rate-limit";

export async function verifyLogin(email: string, password: string, ip: string, now = new Date()) {
  const normalized = email.trim().toLowerCase();
  const keys = [`ip:${ip}`, `email:${normalized}`];
  if (await isRateLimited(keys, now)) throw new RateLimitedError();

  const user = await prisma.user.findUnique({ where: { email: normalized } });
  const ok = user ? await bcrypt.compare(password, user.passwordHash) : false;
  if (!user || !ok) {
    await recordFailures(keys, now);
    return null;
  }
  await clearFailures(keys);
  return { id: user.id, email: user.email, name: user.name };
}
```

```ts
function isRealDate(s: string) {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(s)) return false;
  const d = new Date(`${s}T00:00:00Z`);
  return !Number.isNaN(d.getTime()) && d.toISOString().startsWith(s);
}
```

```ts
import { Prisma } from "@prisma/client";
import type { ZodType } from "zod";
import { requireSession } from "@/lib/auth-guard";
import { DomainError, HttpError, UnauthorizedError } from "@/lib/errors";
import { fieldErrors } from "@/validation/common";

function errorResponse(status: number, error: string, fields?: Record<string, string>) {
  return Response.json(fields ? { error, fields } : { error }, { status });
}

export function route<C>(handler: (req: Request, ctx: C) => Promise<Response>) {
  return async (req: Request, ctx: C): Promise<Response> => {
    try {
      await requireSession();
      return await handler(req, ctx);
    } catch (e) {
      if (e instanceof UnauthorizedError) return errorResponse(401, "Not signed in.");
      if (e instanceof HttpError) return errorResponse(e.status, e.message, e.fields);
      if (e instanceof DomainError) return errorResponse(409, e.message);
      if (e instanceof Prisma.PrismaClientKnownRequestError && e.code === "P2025") return errorResponse(404, "Not found.");
      console.error(e);
      return errorResponse(500, "Something went wrong.");
    }
  };
}

export async function parseJson<T>(req: Request, schema: ZodType<T, any, any>): Promise<T> {
  let body: unknown;
  try {
    body = await req.json();
  } catch {
    throw new HttpError(400, "Request body must be JSON.");
  }
  const result = schema.safeParse(body);
  if (!result.success) throw new HttpError(400, "Please fix the highlighted fields.", fieldErrors(result.error));
  return result.data;
}
```

```ts
import { planVisitUpdate } from "@/domain/visit-rules";
import { prisma } from "@/lib/db";
import { DomainError } from "@/lib/errors";
import { calcAmountDue } from "@/lib/money";
import { addDays, localToUtc } from "@/lib/time";
import type { VisitCreate, VisitFilter, VisitPatch } from "@/validation/visit";

const withStudent = { student: { select: { id: true, name: true } } } as const;

export async function createVisit(input: VisitCreate) {
  const student = await prisma.student.findUniqueOrThrow({ where: { id: input.studentId } });
  if (!student.active) throw new DomainError("Archived students can't get new visits.");
  return prisma.visit.create({
    data: {
      studentId: student.id,
      scheduledAt: localToUtc(input.date, input.time),
      durationMinutes: input.durationMinutes,
      notes: input.notes ?? null,
      rateKopecks: student.hourlyRateKopecks,
      amountDueKopecks: calcAmountDue(student.hourlyRateKopecks, input.durationMinutes),
    },
  });
}

export async function updateVisit(id: string, patch: VisitPatch, now = new Date()) {
  return prisma.$transaction(async (tx) => {
    const current = await tx.visit.findUniqueOrThrow({ where: { id } });
    const data = planVisitUpdate(
      current,
      {
        status: patch.status,
        paid: patch.paid,
        notes: patch.notes,
        durationMinutes: patch.durationMinutes,
        scheduledAt: patch.date && patch.time ? localToUtc(patch.date, patch.time) : undefined,
        paidAt: patch.paidAtDate ? localToUtc(patch.paidAtDate, "12:00") : undefined,
      },
      now,
    );
    return tx.visit.update({ where: { id }, data });
  });
}

export function getVisit(id: string) {
  return prisma.visit.findUnique({ where: { id }, include: withStudent });
}

export function listVisits(filter: VisitFilter = {}) {
  const range =
    filter.from || filter.to
      ? {
          ...(filter.from ? { gte: localToUtc(filter.from, "00:00") } : {}),
          ...(filter.to ? { lt: localToUtc(addDays(filter.to, 1), "00:00") } : {}),
        }
      : undefined;
  return prisma.visit.findMany({
    where: { studentId: filter.studentId, status: filter.status, paid: filter.paid, scheduledAt: range },
    include: withStudent,
    orderBy: { scheduledAt: filter.order ?? "asc" },
  });
}
```

```ts
import type { Prisma, RecurringSeries } from "@prisma/client";
import { occurrencesBetween, type SeriesShape } from "@/domain/recurrence";
import { prisma } from "@/lib/db";
import { DomainError, HttpError } from "@/lib/errors";
import { calcAmountDue } from "@/lib/money";
import { addDays, dateOnly, isoFromDateOnly, localDateString } from "@/lib/time";
import type { SeriesCreate, SeriesPatch } from "@/validation/series";

type Db = Prisma.TransactionClient;

export const HORIZON_DAYS = 56;

function shapeOf(s: RecurringSeries): SeriesShape {
  return {
    weekday: s.weekday,
    startTime: s.startTime,
    durationMinutes: s.durationMinutes,
    startDate: isoFromDateOnly(s.startDate),
    endDate: s.endDate ? isoFromDateOnly(s.endDate) : null,
  };
}

export async function generateForSeries(db: Db, seriesId: string, now: Date): Promise<number> {
  const s = await db.recurringSeries.findUniqueOrThrow({ where: { id: seriesId }, include: { student: true } });
  if (!s.active || !s.student.active) return 0;
  const today = localDateString(now);
  const occurrences = occurrencesBetween(shapeOf(s), today, addDays(today, HORIZON_DAYS)).filter((o) => o.scheduledAt > now);
  if (occurrences.length === 0) return 0;
  const rate = s.student.hourlyRateKopecks;
  const { count } = await db.visit.createMany({
    data: occurrences.map((o) => ({
      studentId: s.studentId,
      seriesId: s.id,
      occurrenceDate: dateOnly(o.occurrenceDate),
      scheduledAt: o.scheduledAt,
      durationMinutes: s.durationMinutes,
      rateKopecks: rate,
      amountDueKopecks: calcAmountDue(rate, s.durationMinutes),
    })),
    skipDuplicates: true,
  });
  return count;
}

async function removeFutureScheduled(db: Db, where: Prisma.VisitWhereInput, now: Date) {
  await db.visit.deleteMany({ where: { ...where, status: "scheduled", scheduledAt: { gt: now } } });
}

export function createSeries(input: SeriesCreate, now = new Date()) {
  return prisma.$transaction(async (tx) => {
    const student = await tx.student.findUniqueOrThrow({ where: { id: input.studentId } });
    if (!student.active) throw new DomainError("Archived students can't get weekly lessons.");
    const series = await tx.recurringSeries.create({
      data: {
        studentId: input.studentId,
        weekday: input.weekday,
        startTime: input.startTime,
        durationMinutes: input.durationMinutes,
        startDate: dateOnly(input.startDate),
        endDate: input.endDate ? dateOnly(input.endDate) : null,
      },
    });
    await generateForSeries(tx, series.id, now);
    return series;
  });
}

export function updateSeries(id: string, patch: SeriesPatch, now = new Date()) {
  return prisma.$transaction(async (tx) => {
    const current = await tx.recurringSeries.findUniqueOrThrow({ where: { id } });
    if (patch.endDate && patch.endDate < isoFromDateOnly(current.startDate)) {
      throw new HttpError(400, "Please fix the highlighted fields.", {
        endDate: "End date must be on or after the first date",
      });
    }
    const series = await tx.recurringSeries.update({
      where: { id },
      data: {
        weekday: patch.weekday,
        startTime: patch.startTime,
        durationMinutes: patch.durationMinutes,
        active: patch.active,
        ...(patch.endDate !== undefined ? { endDate: patch.endDate ? dateOnly(patch.endDate) : null } : {}),
      },
    });
    await removeFutureScheduled(tx, { seriesId: id }, now);
    await generateForSeries(tx, id, now);
    return series;
  });
}

export async function endAllSeriesForStudent(db: Db, studentId: string, now: Date) {
  await db.recurringSeries.updateMany({ where: { studentId, active: true }, data: { active: false } });
  await removeFutureScheduled(db, { studentId, seriesId: { not: null } }, now);
}

export async function generateAll(now = new Date()): Promise<number> {
  const series = await prisma.recurringSeries.findMany({
    where: { active: true, student: { active: true } },
    select: { id: true },
  });
  let created = 0;
  for (const s of series) created += await generateForSeries(prisma, s.id, now);
  return created;
}
```

```ts
import { toast } from "sonner";
import type { FieldErrors } from "@/validation/common";

export type SendResult = { ok: true; data: unknown } | { ok: false; fields: FieldErrors };

export async function send(url: string, method: "POST" | "PATCH", body: unknown): Promise<SendResult> {
  let res: Response;
  try {
    res = await fetch(url, { method, headers: { "content-type": "application/json" }, body: JSON.stringify(body) });
  } catch {
    toast.error("Network error. Check your connection and try again.");
    return { ok: false, fields: {} };
  }
  const json = await res.json().catch(() => ({}));
  if (res.ok) return { ok: true, data: json };
  if (res.status === 401) {
    window.location.href = "/login";
    return { ok: false, fields: {} };
  }
  if (json.fields) return { ok: false, fields: json.fields };
  toast.error(json.error ?? "Something went wrong.");
  return { ok: false, fields: {} };
}
```

```ts
import type { Prisma } from "@prisma/client";
import { emptyStats, owedKopecks, PERIOD_BUCKETS, revenueSeries, studentBreakdown } from "@/domain/analytics";
import { prisma } from "@/lib/db";
import type { Period } from "@/lib/time";

const factSelect = {
  studentId: true, status: true, scheduledAt: true, durationMinutes: true,
  amountDueKopecks: true, paid: true, paidAt: true,
} satisfies Prisma.VisitSelect;

const withStudent = { student: { select: { id: true, name: true } } } as const;

export async function getRevenue(period: Period, now: Date) {
  const visits = await prisma.visit.findMany({ where: { status: "completed" }, select: factSelect });
  return revenueSeries(visits, period, now, PERIOD_BUCKETS[period]);
}

export async function getStudentBreakdown() {
  const [students, visits] = await Promise.all([
    prisma.student.findMany({ orderBy: { name: "asc" }, select: { id: true, name: true, active: true } }),
    prisma.visit.findMany({ where: { status: { in: ["completed", "no_show"] } }, select: factSelect }),
  ]);
  const stats = studentBreakdown(visits);
  return students
    .filter((s) => s.active || stats.has(s.id))
    .map((s) => ({ ...s, ...(stats.get(s.id) ?? emptyStats()) }));
}

export async function getDashboard(now: Date) {
  const weekAhead = new Date(now.getTime() + 7 * 86_400_000);
  const [completed, needsMarking, upcoming] = await Promise.all([
    prisma.visit.findMany({ where: { status: "completed" }, select: factSelect }),
    prisma.visit.findMany({ where: { status: "scheduled", scheduledAt: { lt: now } }, include: withStudent, orderBy: { scheduledAt: "asc" } }),
    prisma.visit.findMany({ where: { status: "scheduled", scheduledAt: { gte: now, lt: weekAhead } }, include: withStudent, orderBy: { scheduledAt: "asc" } }),
  ]);
  const [month] = revenueSeries(completed, "month", now, 1);
  return { owedKopecks: owedKopecks(completed), month, needsMarking, upcoming };
}
```

````markdown
## Architecture

- `src/domain/`: pure business rules with no I/O. `visit-rules.ts` covers charging and paid/status rules, `recurrence.ts` produces weekly occurrences in a time zone, `analytics.ts` does aggregation. Change rules here, with unit tests.
- `src/server/`: Prisma-backed services. Functions take `now` so tests are deterministic. Server-component pages call these directly for reads.
- `src/app/api/**`: mutation endpoints only, each wrapped in `route()` from `src/lib/api.ts`. The wrapper checks the session, parses with Zod and maps errors to 400/401/404/409/500 as `{ error, fields? }`.
- `src/validation/`: Zod schemas shared by client forms and route handlers.
- Auth: `src/auth.config.ts` is edge-safe and used by `src/middleware.ts`. `src/auth.ts` has the Credentials provider, which delegates to `src/server/login.ts` (bcrypt + Postgres-backed rate limit). Pages call `requirePageSession()` and handlers call `requireSession()`.

## Invariants that are easy to break

- Money is integer kopecks everywhere. Format only in the UI via `formatRub`. Parse user input with `parseRubles`, which accepts "1 500,50".
- The DB stores UTC. All local interpretation goes through `src/lib/time.ts` with `APP_TIMEZONE`. Clients send local `YYYY-MM-DD` / `HH:MM` strings and the server converts them. Never use server-local `Date` getters in business logic.
- Only `completed` visits are charged, and paid implies completed (`planVisitUpdate`). `Visit.rateKopecks` is a snapshot, so changing a student's rate never rewrites existing visits.
- Recurring visits are real `Visit` rows generated 8 weeks ahead, extended by the daily cron. `createMany({ skipDuplicates })` on `(seriesId, occurrenceDate)` makes generation idempotent. Editing a series deletes its future `scheduled` visits and regenerates. Archiving a student ends their series.
- Integration tests mock only `@/lib/auth-guard`. Never mock the database.
````
